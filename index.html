Agente de Navegador · Chrome

Conecte o NEX à extensão Chrome e envie comandos explícitos para uma única aba HTTPS autorizada por você.

1. Instale a extensão

Baixe o ZIP, extraia e carregue a pasta extension/sala-do-futuro em chrome://extensions com o Modo do desenvolvedor ativado.

Baixar extensão (ZIP)

2. Autorize a página que deseja controlar

  1. Abra o site de destino em uma aba HTTPS.
  2. Abra o popup da extensão nessa aba e clique em Autorizar esta aba.
  3. Clique em Gerar código de pareamento e copie o código temporário.
  4. Volte para o NEX e cole o código abaixo.

3. Parear o NEX com a extensão

Agente de programação local

Para o NEX criar e editar arquivos no Windows, inicie o agente local. Ele aceita operações apenas dentro da pasta de trabalho Documentos/NEX-Workspace.

  1. Atualize a pasta do projeto NEX.
  2. Dê dois cliques em start-nex-agent.bat.
  3. Copie o token exibido no terminal.
  4. Cole o token aqui e clique em Conectar.

Agente local não verificado.

O servidor aceita apenas conexões locais, exige token e bloqueia caminhos fora do workspace. Execução permitida: npm test, scripts npm, Node e Python dentro da pasta.

4. Comandos pelo chat

Depois de parear, envie um destes comandos no chat:

  • ler página
  • passar mouse sobre Tarefa 5
  • abrir https://exemplo.com
  • clicar em Pesquisar
  • preencher campo Nome com Kaue
  • marcar Certo na questão 2
  • voltar, avançar ou recarregar

O comando de mouse rola até o elemento e envia eventos pointer/mouse para handlers JavaScript; não garante CSS :hover que dependa do cursor físico. O preenchimento não envia formulários. Botões de envio, ações em formulários, campos de senha, códigos de autenticação e dados de pagamento são bloqueados. Use o Kill-Switch no popup para pausar comandos.

A extensão só controla a aba autorizada. Ao navegar para outro domínio, autorize novamente a nova página pelo popup. O acesso à página é restrito à origem HTTPS autorizada; nenhum cookie ou senha é lido.
